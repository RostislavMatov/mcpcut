# A11y/UX-ревью мокапа Ivory Console (2026-08-12)

Ревью `ivory-console.html` + `design-tokens.md` (агент ecc:a11y-architect, WCAG 2.2).
Статус: все находки CRITICAL/HIGH и большинство MEDIUM/LOW **исправлены в мокапе** в тот же день.
Отчёт сохранён как чек-лист паттернов для переноса в реальный server-rendered UI (M-волны редизайна).

## Исправлено в мокапе

- **CRITICAL** — фильтр-чипы (`kind ▾` и др.) и тумблер «Пауза» были `<span>` без роли/фокуса → стали `<button>` (+`aria-haspopup="listbox"`, `aria-pressed`).
- **HIGH** — фейковый `role="tablist"` без клавиатурного паттерна APG → заменён на честный `<nav>` + `aria-current` (для реального UI: либо полный tablist с roving tabindex и стрелками, либо обычные ссылки).
- **HIGH** — «Сбросить» и «Удалить» были `<a href="#">` → стали `<button class="link-btn">`; для необратимого «Удалить» это обязательный паттерн.
- **HIGH** — при переключении экранов фокус не переводился → после смены секции фокус ставится на её `<h1 tabindex="-1">`.
- **HIGH** — гистограмма по часам `#hours` не имела данных для AT → `role="img"` + aria-label с итогами и пиком; строки `.histo-row` получили aria-label «тулза: N allow, M gated».
- **HIGH** — счётчики в сайдбаре «7 / 2» различались только цветом → добавлены sr-only подписи («всего ожидают» / «ожидание агента истекло»).
- **HIGH** — `.dot-alert` (widened) была голой цветной точкой с `title` → добавлен sr-only текст.
- **HIGH** — крестики `.chip .x` ~12px → минимум 24×24px (SC 2.5.8).
- **HIGH** — `disabled` nav-пункты выпадали из tab-order (title недоступен с клавиатуры) → `aria-disabled="true"` с сохранением фокусируемости.
- **MEDIUM** — `.modes` c `aria-pressed` → `role="radiogroup"`/`role="radio"`/`aria-checked` (взаимоисключающий выбор).
- **MEDIUM** — `aria-current="page"` на кнопках без роутинга → `aria-current="true"`.
- **MEDIUM** — `.lane-collapsed` без `aria-expanded` → добавлен.
- **MEDIUM** — декоративные `svg.ic` → `aria-hidden="true"` глобально.
- **MEDIUM** — подпись про query-строку заявляла нереализованное поведение как факт → переформулирована («в реализации: …»).
- **MEDIUM** — «Обновить» в `.freshness` был ниже 24px → увеличен паддинг.
- **LOW** — `summary` добавлен в глобальный focus-visible селектор; границы чипов усилены до `--border-strong`; цвет ссылок в тёмной карточке вынесен в токен `--accent-on-dark`; h6 в сайдбаре заменены на div (иерархия заголовков); `.logout` увеличен до ~38px.

## Осталось для реализации (не для мокапа)

1. **aria-live регион для смен состояния** очереди: переход карточки между лейнами (ожидание истекло, окно гранта истекло) должен анонсироваться один раз через скрытый `aria-live="polite"`; тикающие таймеры в live-регион НЕ оборачивать (спам анонсов).
2. **Пилюля «N новых записей»**: анонсировать только появление (переход скрыто→видно), не каждый инкремент счётчика.
3. **Табы страницы сервера**: при реализации выбрать между полным APG-tablist (roving tabindex + стрелки + aria-controls/tabpanel) и обычными ссылками с `aria-current` — не смешивать.
4. **Скрытая таблица-альтернатива** для гистограммы по часам (sr-only `<table>` час/allow/gated), когда появятся реальные данные агрегатора.
5. **Deep-linking**: переключение разделов должно менять URL (history), тогда `aria-current="page"` станет корректным.

## Подтверждено как правильное (сохранить при переносе)

- Все статус-бейджи несут текст, не только цвет; hatch-паттерн gated-баров дублирует цвет формой (переживает grayscale).
- `role="img"` + aria-label с реальными цифрами на «спектре решений» — эталон для остальных графиков.
- Тикающие таймеры без aria-live + уважение `prefers-reduced-motion` — оставить как есть.
- Кнопки Approve/Deny (34px, полная ширина карточки) проходят и минимум, и практический ориентир.
