# ADR-0001: Стек и граница зависимостей

- **Статус**: принято (постфактум, зафиксировано 2026-08-05; фактически действует с M1)
- **Контекст решения**: CLAUDE.md требует зафиксировать стек в ADR при старте кода; M1/M2 уже
  реализованы (927 тестов), ADR оформляет фактически принятое.

## Решение

| Область | Выбор |
|---|---|
| Язык / рантайм | TypeScript (strict), Node ≥ 24 (пол поднят с ≥ 20 решением ADR-0006, 2026-08-13), ESM |
| Тесты | vitest + @vitest/coverage-v8; TDD, coverage ≥ 80% |
| Валидация границ | zod v4 (`strictObject`, `safeParse`-юнионы) |
| Идентификаторы записей журнала | ulid |
| HTTP (M3) | `node:http`, без фреймворка |
| Крипто (M3, вольт) | `node:crypto` (AES-256-GCM) — см. ADR-0003 |
| Прод-зависимости | **только** `ulid` и `zod` (package.json — источник истины) |

## Уточнение против ранней формулировки CLAUDE.md

CLAUDE.md (решение 3) предполагал «типы протокола из `@modelcontextprotocol/sdk`, транспорт свой».
Фактически SDK **не используется вовсе** — ни типы, ни транспорт:

1. Типы SDK привязаны к одной ревизии спеки; нам с M3 нужно одновременно жить в двух моделях
   (sessionful ≤ 2025-11-25 и stateless 2026-07-28, см. ADR-0002) — своя тонкая типизация в
   `src/protocol/mcp.ts` (единственная точка привязки к спеке) дешевле, чем следование churn SDK.
2. Прокси работает с байтами и не должен парсить/пересобирать сообщения (инвариант байт-идентичности);
   полные типы протокола не нужны — только распознавание нескольких форм (`tools/call`, `tools/list`,
   `initialize`, ошибки), реализованное pure-функциями «не бросают, при мусоре — null».
3. Ноль лишних зависимостей — меньше supply-chain поверхность (мы security-продукт).

CLAUDE.md приведён в соответствие 2026-08-13 (решение 3 больше не упоминает SDK).

## Инварианты, которые стек обязан сохранять

- Транспортный слой (`framing`, `splice`, `transport/**`) не знает о JSON-RPC-семантике —
  проверяется тестом графа импортов (`tests/architecture/imports.test.ts`).
- Редакция (`redact`) — единственный путь к персистенции; Authorization/Bearer в журнал не попадают
  никогда (leak-regression тест с маркером).
- Файлы < 400 строк, функции < 50 строк; ошибки — именованные подклассы `Error` c `{cause}`;
  result-юнионы вместо исключений на границах.

## Альтернативы

- **`@modelcontextprotocol/sdk`**: отвергнут (см. выше) — churn версий, ненужный объём, парсинг ломает
  байт-идентичность.
- **HTTP-фреймворк (fastify/hono/express)**: отвергнут — три маршрута не оправдывают зависимость (KISS).
- **Deno/Bun**: отвергнуты — enterprise-таргет ставит Node LTS.

## Последствия

- (+) Аудитоспособная зависимость-поверхность: 2 прод-пакета.
- (−) Формы протокола поддерживаем сами; смягчение — все привязки к спеке в одном модуле
  `protocol/mcp.ts` + матрица `docs/research/http-spec-matrix.md`.
