# Смок: удалённая консоль `mcpcut --remote` (ADR-0014)

Дата: 2026-09-19. Ветка `feat/web-first-owner-setup`, сборка `npm run build` из рабочего дерева.

## Стенд

- Служба: `node dist/cli.js ui --port 18791` над пустым скретч-каталогом данных
  (`MCPCUT_DATA_DIR=<scratch>/data`, без конфига установки, без `MCP_ADMIN_TOKEN` в окружении).
- Клиент: `node dist/cli.js --remote http://127.0.0.1:18791` в псевдотерминале 120×40 (python `pty`),
  со своими `MCPCUT_CONFIG`/`MCPCUT_DATA_DIR`, указывающими в никуда, — у клиента установки нет.
- API — `curl` без заголовка `Origin`.

## Что не прогонялось

- **RC4 с не-loopback пира** (отказ `vault set` по открытому http) — вживую нужен второй хост; покрыто
  тестами `tests/ui/console-run.test.ts` через настроенный `trustedProxyHeader`.
- **https за обратным прокси** (`behindTls`) и настоящий VPS.
- **Services ▸ start/stop** удалённо над установкой с конфигом: стенд поднят голым `ui`, без `setup`.
- **Docker.** Демон на машине разработки выключен.

## Наблюдения

- В шапке основного экрана адреса удалённой установки нет — он виден на экранах входа и первого
  владельца. При работе с несколькими установками этого мало; вынесено в хвосты.
